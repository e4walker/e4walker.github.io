Below is a listing of all the classes I have attended between Massasoit Community College and Bridgewater State University so far.

Massasoit Community College

  • COSC101 - Fundamentals of Computer Science: Learned about the basic fundamentals of computer science, such as the concepts behind computer organization, programming, algorithms, and information processing.
  • COSC123 - Intro to Data Science: Learned about the base topics of data science and big data, such as statistics, probability, visualizing data, and collecting data.
  • COSC157 (COMP 151) - Intro Java Programming: Learned the fundamentals of java, including syntax, sequence, methods, classes, and arrays through coding programs.
  • COSC168 (COMP 152) - Advanced Java Programming: Continuation from Intro Java Programming, where more advanced java topics such as inheritance, interfaces, file input/output, recursion, and exception handling were learned through coding programs.
  • COSC236 (COMP 206) - Computer Architecture: Learned about the basics of Computer Architecture, such as the difference and connection between hardware and software, assembly language, binary, hexadecimal, and machine language/architecture.
  • COSC237 (COMP 250) - Data Structures/Algorithms: An intro to the foundational topics of Data Structures and algorithms, topics learned include linear and non-linear data structures, hashing, recursion, and big-O notation.

Bridgewater State University

  • COMP 111 - Logic And Computers: Learned about the fundamentals of logic and how logic applies to computer technology, working with logic gates and basic logical programming.
  • COMP 340 - Organization of Computer Languages: Learned about the foundational concepts that exist across many different programming languages, covering topics such as object oriented programming, functional programming, dynamic vs. static typed languages, and complied vs. interpreted languages.
  • COMP 430 - Computer Networks: Learned the basics and fundamentals of computer networking, including topics such as data transmission, multiplexing, protocols, packets, and communication processes.
  • COMP 435 - Analysis of Algorithms: A deep dive into the workings of Data Structures and Algorithms, through topics such as data manipulation, graphical analysis, runtime comparison, matrix operations, and dynamic programming.
